# OpenAPI client migration (issue #39)

Notes and test-enforced contracts for migrating `PaletteAPIClient` from the
hand-rolled `URLSession` + `Codable` client onto a typed client generated by
`swift-openapi-generator` from the `color_matching` OpenAPI document.

## Committed layout (enforced by tests)

`ColorComposerCore/Tests/ColorComposerCoreTests/OpenAPIClientMigrationTests.swift`
fails (red) until the migration lands. It enforces:

1. **The OpenAPI document is committed** under
   `ColorComposerCore/OpenAPI/openapi.yaml` (`.yml`/`.json` accepted), and
   describes `printer_profiles`, `colors`, and the `/api/v1` base path.
2. **`ColorComposerCore/Package.swift` declares both dependencies**:
   `swift-openapi-generator` (the generator plugin) and
   `swift-openapi-runtime`.
3. **`OpenAPIRuntime` is linkable** from the package (compile-level check via
   `#if canImport(OpenAPIRuntime)`).

The document itself comes from the backend repo's published spec
(`viamin/color_matching` OpenAPI work); vendor the copy here so generation is
reproducible without a backend checkout.

## Behavior that must not change

The migration must keep `PaletteAPIClient`'s observable contract intact
(wrap the generated client or migrate beneath the same surface). The
permanent wire-contract tests live in
`ColorComposerCore/Tests/ColorComposerCoreTests/PaletteAPIClientTests.swift`
and pin:

- `GET <base>/api/v1/printer_profiles` and
  `GET <base>/api/v1/colors?printer_profile_id=N`, with
  `Accept: application/json`.
- Bearer-token handling: trimmed token → `Authorization: Bearer <token>`;
  empty/nil token → header omitted.
- Error mapping: HTTP 401 → `PaletteAPIError.unauthorized` (drives the
  re-auth flow in `ColorCatalog`), other non-2xx → `.badStatus(code)`,
  undecodable 2xx body → `.malformedResponse`.
- Envelope decoding (`printer_profiles`, `colors` + `printer_profile`)
  including snake-case keys and absent-vs-zero measurement semantics.

The offline machinery is untouched by the migration and stays covered by
`ProfileColorCacheTests` (per-server/per-profile disk cache, normalization,
ownership, clear) — the cache stores wire DTOs, so any generated-client
 DTO conversion must feed it equivalent `PaletteColorDTO` values.
