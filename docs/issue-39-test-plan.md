## Corpus provenance and refresh procedure

The fixture at `ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/solver-parity-v1.json` is copied verbatim from [`viamin/color_matching` `priv/parity/v1/corpus.json`](https://github.com/viamin/color_matching/blob/main/priv/parity/v1/corpus.json), generated by upstream issue [#111](https://github.com/viamin/color_matching/issues/111).

When upstream intentionally changes solver semantics, run `mix parity.generate` in the backend repository, review the resulting `priv/parity/v1/corpus.json`, copy it here under the matching versioned filename, and update the expected `algorithm_version` assertion. Do not refresh the fixture solely to make a divergent client test pass: first review the upstream algorithm/version change and its tie, exclusion, and weight semantics.
