# Solver parity corpus

`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/weighted-squared-error-v1.json`
is a committed copy of the version 1 corpus generated by
`viamin/color_matching` for issue #111. `WeightedSquaredErrorParityTests`
replays every candidate score and each 1x1 solver selection, including ties.

To refresh it after an upstream algorithm-version change, download
`https://raw.githubusercontent.com/viamin/color_matching/main/priv/parity/v1/corpus.json`,
replace the fixture byte-for-byte, then run `swift test` from
`ColorComposerCore`. Update this note and the root README during the
implementation phase when the client migration lands.
