# Solver parity corpus

`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/weighted_squared_error_v1.json`
is the committed v1 parity corpus generated by the backend repository's
`ColorMatching.WeightedSquaredError` implementation. The test
`WeightedSquaredErrorParityCorpusTests` loads it directly and verifies every
candidate score or exclusion, plus solver selection and error for every
representable one-cell target.

The canonical source is
[`viamin/color_matching` `priv/parity/v1/corpus.json`](https://github.com/viamin/color_matching/blob/main/priv/parity/v1/corpus.json).
To refresh it after the backend intentionally publishes a new corpus version:

1. Copy the backend's versioned JSON into this test fixture directory using a
   versioned filename.
2. Update the test to assert the new algorithm version and any new schema.
3. Run `cd ColorComposerCore && swift test --filter WeightedSquaredErrorParityCorpusTests`.
4. Review the resulting selection behavior, especially tied indices,
   missing-measurement exclusions, and zero/unknown weight handling, before
   replacing the existing fixture.

Do not silently overwrite the existing v1 fixture: it is a compatibility
contract for the currently supported solver behavior.
