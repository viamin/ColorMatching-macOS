# Solver parity corpus

`ColorComposerCoreTests/Fixtures/weighted_squared_error_v1.json` is the
committed v1 golden-vector corpus generated by the `color_matching` backend.
`WeightedSquaredErrorParityTests` decodes it and verifies every candidate
score, exclusion, selected color, error, and earliest-index tie result.

The source of truth is
[`viamin/color_matching`'s `priv/parity/v1/corpus.json`](https://github.com/viamin/color_matching/blob/main/priv/parity/v1/corpus.json),
created by issue [viamin/color_matching#111](https://github.com/viamin/color_matching/issues/111).

To refresh after the backend intentionally publishes a new corpus version,
download the corresponding file into the test fixture directory, review the
algorithm-version and scenario changes, then run the core package tests:

```bash
curl -L https://raw.githubusercontent.com/viamin/color_matching/main/priv/parity/v1/corpus.json \
  -o ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/weighted_squared_error_v1.json
cd ColorComposerCore && swift test --filter WeightedSquaredErrorParityTests
```

Do not silently overwrite the fixture: a changed corpus is a cross-service
contract change and requires reviewing the resulting parity assertions.
