# Solver parity corpus

The Swift core replays the committed v1 corpus in
`ColorComposerCore/Tests/ColorComposerCoreTests/Resources/Parity/corpus.json`.
It is a byte-for-byte copy of the upstream `color_matching` corpus at
`priv/parity/v1/corpus.json`, generated by `mix parity.generate`.

Refresh it only after the upstream corpus has changed deliberately:

1. Run `mix parity.generate` in `viamin/color_matching` and commit its result there.
2. Copy the generated `priv/parity/v1/corpus.json` into the Swift test resource.
3. Run `swift test` from `ColorComposerCore`; the replay must match every candidate score, selection, exclusion, and earliest-index tie break.

The implementation phase must add this same consumption note to the root README,
which is outside the tests-only change allowlist for this run.
