# Solver parity corpus

`ColorComposerCoreTests` replays the versioned golden vectors generated by
[`viamin/color_matching`](https://github.com/viamin/color_matching) at
`priv/parity/v1/corpus.json`. The committed local copy belongs at
`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/Parity/v1/corpus.json`.
It covers per-candidate scores, earliest-wins ties, missing-measurement
exclusions, and zero-weight channels for `WeightedSquaredErrorScorer`.

When the server changes solver semantics, run `mix parity.generate` in the
server repository, replace the local fixture with its resulting
`priv/parity/v1/corpus.json`, and run `cd ColorComposerCore && swift test`.
Treat a changed `algorithm_version` as an intentional parity-contract update:
review the new scenarios and expected outputs before committing the refresh.

issue #39.
