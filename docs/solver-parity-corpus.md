# Solver parity corpus

`ColorComposerCoreTests` consumes the committed fixture at
`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/solver-parity-v1.json`.
It is copied from the canonical `viamin/color_matching` corpus at
`priv/parity/v1/corpus.json`, generated by `mix parity.generate`.

When the server changes `ColorMatching.WeightedSquaredError` or its matching
tie policy, regenerate and review the server fixture, replace the committed
macOS fixture byte-for-byte, then run:

```sh
swift test --package-path ColorComposerCore --filter SolverParityCorpusTests
```

The test asserts every score (including `excluded` results), selected index and
hex color, expected error, and the recorded tie indices. It therefore covers
positive-weight channel requirements, zero-weight exclusions, and earliest-wins
ties without redefining solver semantics in the test.
