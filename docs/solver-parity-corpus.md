# Solver parity corpus

`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/weighted_squared_error_v1.json`
is the committed v1 golden-vector corpus for parity with
[`viamin/color_matching`](https://github.com/viamin/color_matching). The
`WeightedSquaredErrorParityCorpusTests` test replays every candidate score and
uses `CompositionSolver` to verify the server's earliest-index-wins selection.

The fixture is generated by the backend's `mix parity.generate` task and is
owned upstream at `priv/parity/v1/corpus.json`. To refresh it after an upstream
algorithm-version change, copy the committed upstream JSON into the fixture
path above, then run `swift test` from `ColorComposerCore`. Review
any expected changes for selection ties, missing positive-weight channels, and
channel weights before committing the refresh.

The corpus is intentionally checked in: client parity must be reproducible
without network access or a running backend.
