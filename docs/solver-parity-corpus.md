# Solver parity corpus

`ColorComposerCoreTests/Fixtures/weighted-squared-error-v1-corpus.json` is the
committed v1 golden corpus for `WeightedSquaredErrorScorer` and
`CompositionSolver`'s earliest-index tie selection. Its upstream source is
`viamin/color_matching` at `priv/parity/v1/corpus.json`, generated by
`mix parity.generate`.

To refresh it after the backend intentionally changes the scorer contract:

1. Update the upstream checkout and regenerate its corpus with
   `mix parity.generate`.
2. Copy the resulting `priv/parity/v<N>/corpus.json` to the matching fixture
   path in this package.
3. Update `WeightedSquaredErrorParityCorpusTests` for the new algorithm
   version, then run `swift test` from `ColorComposerCore`.

The corpus asserts per-candidate scores and the selected palette index. It
covers exact ties, missing-measurement exclusion, zero-weight channels, and
unknown backend-only weights.
