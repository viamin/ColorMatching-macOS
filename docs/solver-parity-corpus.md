# Solver parity corpus

`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/parity/v1/corpus.json`
is the committed golden-vector corpus generated by
[`viamin/color_matching`](https://github.com/viamin/color_matching) issue #111.
`SolverParityCorpusTests` replays every vector through
`WeightedSquaredErrorScorer`, including selection order, exact scores, ties,
missing-measurement exclusions, and positive/zero channel weights.

Refresh it by downloading the upstream committed corpus, then run:

```bash
cd ColorComposerCore
swift test --filter SolverParityCorpusTests
```

Keep the upstream corpus versioned under `Fixtures/parity/v<algorithm_version>/`.
