# Solver parity corpus

`ColorComposerCoreTests` consumes the committed v1 corpus at
`ColorComposerCore/Tests/ColorComposerCoreTests/Fixtures/solver-parity-v1.json`.
Its canonical upstream source is
[`viamin/color_matching`'s `priv/parity/v1/corpus.json`](https://github.com/viamin/color_matching/blob/main/priv/parity/v1/corpus.json),
generated by `mix parity.generate` in that repository.

Refresh the fixture only after the server corpus has been regenerated and its
`algorithm_version` reviewed. Download the canonical file, replace the local
fixture byte-for-byte, and run:

```bash
cd ColorComposerCore
swift test --filter SolverParityCorpusTests
```

The tests pin all candidate scores, exclusions, selected palette entries, and
earliest-index tie breaking. A corpus version change requires a deliberate
client compatibility review rather than a fixture-only update.
